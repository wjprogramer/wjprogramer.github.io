# Badminton Notes - 羽毛球筆記網站

## 專案概述

這是一個關於羽毛球的筆記網站，旨在系統化整理羽毛球相關知識，幫助加深對羽毛球的理解，並提升在球場上的表現。

## 專案定位

- **個人學習筆記** + **教學資源分享**
- 內容深度完整，涵蓋初學到進階的所有層級
- 目標：別人看得懂，自己也能用

## 核心價值

1. **對羽球理解更深刻** - 透過系統化的知識整理，加深對羽毛球的理解
2. **在球場上表現更好** - 提供實用的技術、戰術和訓練方法，幫助實際應用
