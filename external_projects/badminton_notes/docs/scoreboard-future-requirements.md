# 記分板工具 - 未來功能需求

本文檔記錄記分板工具的未來擴展功能需求。

---

## 功能需求

### 1. 隊伍與選手管理

#### 需求描述

可以將隊伍和底下的使用者（選手）儲存下來，下次使用時可以透過挑選的方式快速選擇，無需重新輸入。

#### 功能細節

**1.1 隊伍儲存**

- 儲存隊伍名稱
- 儲存隊伍成員（選手）資訊
  - 選手名稱
  - 選手頭像（可選）
  - 選手編號（可選）
- 支援多個隊伍的儲存和管理

**1.2 選手儲存**

- 儲存選手基本資訊
  - 選手名稱
  - 選手頭像（可選）
  - 選手編號（可選）
  - 常用位置（左邊/右邊，適用於雙打）
- 選手可以屬於多個隊伍（例如：俱樂部選手可能參加不同隊伍）

**1.3 快速選擇介面**

- 開始新比賽時，提供「選擇隊伍」或「選擇選手」的選項
- 顯示已儲存的隊伍列表
- 顯示已儲存的選手列表
- 支援搜尋功能（依名稱搜尋隊伍或選手）
- 支援編輯和刪除已儲存的隊伍/選手

### 2. 多種賽制支援

#### 需求描述

支援不同的比賽賽制，包括循環賽、單淘汰賽、雙淘汰賽等，讓使用者可以組織和管理完整的比賽。

#### 功能細節

**2.1 支援的賽制**

**2.1.1 循環賽（Round Robin）**

- 所有參賽隊伍/選手互相對戰
- 每場比賽記錄分數和勝負
- 計算總積分、勝場數、負場數
- 支援排名顯示

**2.1.2 單淘汰賽（Single Elimination）**

- 樹狀結構對戰
- 輸一場即淘汰
- 自動配對下一輪對手
- 顯示對戰樹狀圖

**2.1.3 雙淘汰賽（Double Elimination）**

- 輸兩場才淘汰
- 包含勝部組和敗部組
- 勝部組冠軍與敗部組冠軍對戰
- 顯示複雜的對戰樹狀圖

**2.1.4 分組循環賽（Group Stage + Knockout）**

- 先進行分組循環賽
- 各組前幾名進入淘汰賽
- 結合循環賽和淘汰賽的優點

**2.2 比賽管理功能**

**2.2.1 比賽創建**

- 選擇賽制類型
- 設定參賽隊伍/選手數量
- 設定比賽規則（局數、分數等）
- 設定比賽時間和地點（可選）

**2.2.2 對戰配對**

- 自動生成對戰表
- 支援手動調整對戰順序
- 顯示當前輪次和對戰狀態

**2.2.3 比賽進度追蹤**

- 顯示已完成、進行中、未開始的比賽
- 顯示當前輪次
- 顯示晉級情況

**2.2.4 結果統計**

- 顯示各隊伍/選手的戰績
- 顯示積分排名
- 顯示對戰記錄
- 支援匯出比賽結果

## 技術實現考量

### 數據儲存

- 使用 `localStorage` 儲存隊伍、選手和比賽數據
- 考慮數據量增長，可能需要實作數據清理機制
- 未來可考慮使用 IndexedDB 儲存大量數據

### 性能優化

- 對戰樹狀圖的渲染優化
- 大量比賽數據的查詢和排序優化
- 使用虛擬滾動處理長列表

### 用戶體驗

- 提供清晰的視覺化對戰表
- 支援拖放調整對戰順序（可選）
- 提供比賽進度的視覺化指示
- 支援比賽結果的匯出和分享
