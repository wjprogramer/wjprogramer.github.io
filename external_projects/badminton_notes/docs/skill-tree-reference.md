## 技能樹結構總覽

技能樹分為四個主要階段，從基礎到進階，每個技能都有明確的前置依賴關係：

1. **基礎階段（Foundation）** - 白色背景
2. **初階（Beginner）** - 淺黃色背景
3. **中階（Intermediate）** - 淺橙色背景
4. **進階（Advance）** - 淺紅色背景

---

## 階段一：基礎階段（Foundation）

### 一般概念

- **步法** (Footwork)
- **握拍處理** (Racket Handling)
- **發球** (Serves)
- **擊球** (Shots)
- **姿勢** (Form)

### 移動與步法（紫色節點）

#### 核心步法技術

- **分腿步** (Split Step)

  - → 側併步 (Chasse)
  - → 方向性分腿步 (Directional Split Step)

- **側併步** (Chasse)

  - → 後交叉步 (Back Crossover)

- **後交叉步** (Back Crossover)

  - → 正手步法 (Forehand Footwork)
  - → 後場正手步法 (Rear Forehand Footwork)

- **非持拍軸心** (Non-Racket Pivot)

  - → 反手步法 (Backhand Footwork)
  - → 後場反手步法 (Rear Backhand Footwork)

- **弓箭步** (Lunge)
  - → 反手步法 (Backhand Footwork)
  - → 後場反手步法 (Rear Backhand Footwork)

#### 基礎步法列表

- 反手步法 (Backhand Footwork)
- 後場反手步法 (Rear Backhand Footwork)
- 正手步法 (Forehand Footwork)
- 後場正手步法 (Rear Forehand Footwork)
- 方向性分腿步 (Directional Split Step)

### 握拍與前臂力學（綠色節點）

#### 握拍技術

- **手指擠壓** (Finger Squeeze)

  - → 前臂旋前 (Forearm Pronation)

- **斜面握拍** (Bevel Grip)

  - → 前臂旋後 (Forearm Supination)

- **平底鍋握拍** (Panhandle Grip)

  - → 握拍切換 (Grip Switch)

- **反手握拍** (Backhand Grip)

  - → 握拍切換 (Grip Switch)

- **正手握拍** (Forehand Grip)
  - → 握拍切換 (Grip Switch)

#### 前臂力學

- **前臂旋前** (Forearm Pronation)
- **前臂旋後** (Forearm Supination)
- **握拍切換** (Grip Switch)

## 階段二：初階（Beginner）

### 步法相關技術

- **反手步法** (Backhand Footwork)

  - → 反手網前 (Backhand Net)
  - → 反手挑球 (Backhand Lift)

- **正手步法** (Forehand Footwork)

  - → 正手網前 (Forehand Net)
  - → 正手挑球 (Forehand Lift)

- **後場正手步法** (Rear Forehand Footwork)
  - → 高遠球 (Clear)

### 前臂力學相關技術

- **前臂旋前** (Forearm Pronation)

  - → 反手平抽 (Backhand Drive)
  - → 正手平抽 (Forehand Drive)

- **前臂旋後** (Forearm Supination)
  - → 反手平抽 (Backhand Drive)
  - → 正手平抽 (Forehand Drive)

### 握拍切換相關技術

- **握拍切換** (Grip Switch)
  - → 防守姿勢 (Defensive Form)
  - → 攻擊姿勢 (Aggressive Form)
  - → 接發球姿勢 (Service Return Form)

### 發球技術

- **反手發球** (Backhand Serve)
- **正手發球** (Forehand Serve)

### 初階技能完整列表

1. 反手網前 (Backhand Net)
2. 正手網前 (Forehand Net)
3. 反手挑球 (Backhand Lift)
4. 正手挑球 (Forehand Lift)
5. 高遠球 (Clear)
6. 反手平抽 (Backhand Drive)
7. 正手平抽 (Forehand Drive)
8. 防守姿勢 (Defensive Form)
9. 攻擊姿勢 (Aggressive Form)
10. 接發球姿勢 (Service Return Form)
11. 反手發球 (Backhand Serve)
12. 正手發球 (Forehand Serve)

## 階段三：中階（Intermediate）

### 網前技術

- **反手網前** (Backhand Net)

  - → 反手網前旋轉 (Backhand Net Spin)

- **正手網前** (Forehand Net)

  - → 正手網前旋轉 (Forehand Net Spin)

- **防守姿勢** (Defensive Form)
  - → 防守網前 (Defence Net)
  - → 反手網前封殺 (Backhand Net Kill)
  - → 正手網前封殺 (Forehand Net Kill)

### 後場技術

- **反手挑球** (Backhand Lift)

  - → 防守挑球 (Defence Lift)

- **正手挑球** (Forehand Lift)

  - → 防守挑球 (Defence Lift)

- **高遠球** (Clear)
  - → 繞頭高遠球 (Round The Head Clear)

### 中場技術

- **反手平抽** (Backhand Drive)

  - → 反手吊球 (Backhand Drop)

- **正手平抽** (Forehand Drive)
  - → 正手吊球 (Forehand Drop)

### 攻擊技術

- **攻擊姿勢** (Aggressive Form)
  - → 殺球 (Smash)
  - → 反手網前封殺 (Backhand Net Kill)
  - → 正手網前封殺 (Forehand Net Kill)

### 發球技術

- **接發球姿勢** (Service Return Form)
  - → 反手彈發球 (Backhand Flick Serve)

### 中階技能完整列表

1. 反手網前旋轉 (Backhand Net Spin)
2. 正手網前旋轉 (Forehand Net Spin)
3. 防守網前 (Defence Net)
4. 防守挑球 (Defence Lift)
5. 反手吊球 (Backhand Drop)
6. 繞頭高遠球 (Round The Head Clear)
7. 殺球 (Smash)
8. 正手吊球 (Forehand Drop)
9. 反手網前封殺 (Backhand Net Kill)
10. 正手網前封殺 (Forehand Net Kill)
11. 反手彈發球 (Backhand Flick Serve)

## 階段四：進階（Advance）

### 進階攻擊技術

- **反手網前旋轉** (Backhand Net Spin)

  - → 反手殺球 (Backhand Smash)

- **防守網前** (Defence Net)

  - → 反手殺球 (Backhand Smash)

- **防守挑球** (Defence Lift)

  - → 反手高遠球 (Backhand Clear)

- **反手吊球** (Backhand Drop)

  - → 反手高遠球 (Backhand Clear)

- **繞頭高遠球** (Round The Head Clear)

  - → 剪刀跳殺球 (Scissor Kick Smash)

- **殺球** (Smash)

  - → 跳殺 (Jump Smash)
  - → 跳殺出界 (Jump Out Smash)

- **正手吊球** (Forehand Drop)
  - → 跳殺出界 (Jump Out Smash)

### 進階網前技術

- **反手網前封殺** (Backhand Net Kill)

  - → 反手網前刷球 (Backhand Net Brush)

- **正手網前封殺** (Forehand Net Kill)
  - → 正手網前刷球 (Forehand Net Brush)

### 進階技能完整列表

1. 反手殺球 (Backhand Smash)
2. 反手高遠球 (Backhand Clear)
3. 剪刀跳殺球 (Scissor Kick Smash)
4. 跳殺 (Jump Smash)
5. 跳殺出界 (Jump Out Smash)
6. 反手網前刷球 (Backhand Net Brush)
7. 正手網前刷球 (Forehand Net Brush)

## 技能依賴關係總結

### 基礎 → 初階

- **步法基礎** → 網前技術、挑球、高遠球
- **前臂力學** → 平抽技術
- **握拍切換** → 各種姿勢（防守、攻擊、接發球）

### 初階 → 中階

- **網前技術** → 網前旋轉、網前封殺
- **挑球技術** → 防守挑球
- **高遠球** → 繞頭高遠球
- **平抽技術** → 吊球
- **姿勢技術** → 殺球、防守網前、網前封殺

### 中階 → 進階

- **網前旋轉/防守網前** → 反手殺球
- **防守挑球/反手吊球** → 反手高遠球
- **繞頭高遠球** → 剪刀跳殺球
- **殺球/正手吊球** → 跳殺、跳殺出界
- **網前封殺** → 網前刷球

## 學習路徑建議

### 第一階段：建立基礎

1. 掌握基本步法（分腿步、側併步、弓箭步）
2. 學習各種握拍方式
3. 練習前臂旋前/旋後動作
4. 掌握握拍切換技巧

### 第二階段：基礎應用

1. 從步法發展到網前技術
2. 從前臂力學發展到平抽技術
3. 從握拍切換發展到各種姿勢
4. 學習基本發球技術

### 第三階段：技術精進

1. 網前技術進階（旋轉、封殺）
2. 後場技術進階（繞頭高遠球、防守挑球）
3. 中場技術進階（吊球）
4. 攻擊技術進階（殺球）

### 第四階段：高階應用

1. 進階攻擊技術（跳殺、剪刀跳殺）
2. 進階網前技術（網前刷球）
3. 反手高階技術（反手殺球、反手高遠球）

## 備註

- 此技能樹為參考資料，可作為學習路徑規劃的依據
- 實際學習時應根據個人情況調整進度
- 某些技能可能需要同時掌握多個前置技能
- 建議在教練指導下進行技術練習
