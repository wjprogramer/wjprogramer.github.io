# 頁面結構規劃

## 主要頁面

### 1. 首頁 (Home)

- 網站介紹
- 快速導航
- 推薦內容
- 學習路徑入口

### 2. 內容列表頁 (Content List)

- 按技術類型分類瀏覽
- 按情境分類瀏覽（單打、雙打、混雙、通用）
- 標籤篩選
- 搜尋功能
- 收藏內容列表

### 3. 內容詳情頁 (Content Detail)

- 內容標題
- 分類標籤（技術類型、情境）
- 內容主體（支援多種格式：文字、圖片、影片、互動內容等）
- 相關技術連結
- 技術對比（如適用）
- 情境應用說明（如適用）
- 練習計畫範例（如適用）
- 常見問題 FAQ（如適用）
- 收藏按鈕

### 4. 學習路徑頁 (Learning Path)

- 推薦閱讀順序
- 進度顯示（視覺化）
- 相關內容連結

### 5. 搜尋結果頁 (Search Results)

- 搜尋關鍵字
- 搜尋結果列表
- 篩選選項

### 6. 收藏頁 (Favorites)

- 收藏的內容列表
- 分類顯示
- 快速移除收藏

## 導航結構

```text
首頁
├── 學習路徑
├── 內容瀏覽
│   ├── 按技術類型
│   │   ├── 基礎知識
│   │   ├── 基礎動作
│   │   ├── 發球技術
│   │   ├── 擊球技術
│   │   ├── 步法移動
│   │   └── 戰術運用
│   └── 按情境
│       ├── 單打
│       ├── 雙打
│       ├── 混雙
│       └── 通用
├── 搜尋
└── 收藏
```

## 頁面元件

### 通用元件

- Header（網站標題、語言切換、主題切換、搜尋入口）
- Navigation（主要導航選單）
- Footer（版權資訊、相關連結）
- Breadcrumb（麵包屑導航）

### 內容相關元件

- ContentCard（內容卡片）
- Tag（標籤）
- RelatedLinks（相關技術連結）
- Comparison（技術對比）
- PracticePlan（練習計畫範例）
- FAQ（常見問題）
