# Crontab Guru 功能規格

## 功能概述

**Crontab Guru** 是一個 Cron 排程表達式解析和解釋工具，幫助開發者理解 Cron 表達式的含義，並預覽執行時間。

參考網站：https://crontab.guru/

---

## 核心功能

### 1. Cron 表達式解析

#### 1.1 輸入方式

**方式 A：單一輸入框**

- 輸入完整的 cron 表達式：`0 9 * * 1-5`
- 支援空格分隔的 5 個欄位

**方式 B：分欄位輸入（可選）**

- 分鐘：`0`
- 小時：`9`
- 日期：`*`
- 月份：`*`
- 星期：`1-5`

#### 1.2 即時解析

- 輸入時即時解析並顯示結果
- 無需點擊按鈕即可看到解釋

---

### 2. 人類可讀解釋

將 cron 表達式轉換為自然語言說明：

| Cron 表達式      | 解釋範例                      |
| ---------------- | ----------------------------- |
| `0 9 * * *`      | "每天 09:00"                  |
| `0 9 * * 1-5`    | "每週一至週五 09:00"          |
| `*/5 * * * *`    | "每 5 分鐘"                   |
| `0 0 1 * *`      | "每月 1 號 00:00"             |
| `0 0 * * 0`      | "每週日 00:00"                |
| `0 9-17 * * 1-5` | "每週一至週五 09:00 至 17:00" |
| `0 0 1,15 * *`   | "每月 1 號和 15 號 00:00"     |
| `0 */2 * * *`    | "每 2 小時"                   |

**解釋規則**：

- 優先顯示具體時間（如果有）
- 顯示重複頻率（每天、每週、每月等）
- 顯示範圍（週一至週五、09:00-17:00 等）
- 顯示列表值（1,15 號等）

---

### 3. 執行時間預覽

#### 3.1 下一次執行時間

顯示下一次任務執行的完整時間：

- 格式：`YYYY-MM-DD HH:mm:ss`
- 範例：`2025-12-20 09:00:00`
- 即時更新（根據當前時間計算）

#### 3.2 未來執行時間列表

顯示未來 10 次執行時間：

```
1. 2025-12-20 09:00:00 (明天)
2. 2025-12-21 09:00:00 (後天)
3. 2025-12-22 09:00:00 (週一)
...
10. 2025-12-29 09:00:00
```

---

### 4. 語法驗證

#### 4.1 即時驗證

- 輸入時即時檢查語法
- 無效表達式顯示錯誤訊息

#### 4.2 錯誤提示

| 錯誤類型     | 提示訊息                       |
| ------------ | ------------------------------ |
| 欄位數量錯誤 | "Cron 表達式應包含 5 個欄位"   |
| 無效數字     | "分鐘欄位應為 0-59 之間的數字" |
| 無效範圍     | "範圍起始值不能大於結束值"     |
| 無效步進值   | "步進值必須大於 0"             |

#### 4.3 修正建議

- 自動修正常見錯誤
- 提供修正建議

---

### 5. 常用範例

提供快速選擇的常用 cron 表達式：

| 範例      | Cron 表達式   | 說明                    |
| --------- | ------------- | ----------------------- |
| 每分鐘    | `* * * * *`   | 每分鐘執行一次          |
| 每小時    | `0 * * * *`   | 每小時的 0 分執行       |
| 每天      | `0 0 * * *`   | 每天 00:00 執行         |
| 每週      | `0 0 * * 0`   | 每週日 00:00 執行       |
| 每月      | `0 0 1 * *`   | 每月 1 號 00:00 執行    |
| 工作日    | `0 9 * * 1-5` | 每週一至週五 09:00 執行 |
| 每 5 分鐘 | `*/5 * * * *` | 每 5 分鐘執行一次       |
| 每 2 小時 | `0 */2 * * *` | 每 2 小時執行一次       |

---

### 6. 隨機生成

- 點擊「隨機」按鈕生成隨機的 cron 表達式
- 用於學習和測試
- 生成的表達式都是有效的

---

### 7. 語法說明表格

顯示 cron 表達式的語法說明：

| 欄位 | 允許值          | 特殊符號                    |
| ---- | --------------- | --------------------------- |
| 分鐘 | 0-59            | `*` `,` `-` `/`             |
| 小時 | 0-23            | `*` `,` `-` `/`             |
| 日期 | 1-31            | `*` `,` `-` `/` `?` `L` `W` |
| 月份 | 1-12 或 JAN-DEC | `*` `,` `-` `/`             |
| 星期 | 0-7 或 SUN-SAT  | `*` `,` `-` `/` `?` `L` `#` |

**特殊符號說明**：

- `*` - 任何值
- `,` - 值列表分隔符（例如：`1,3,5`）
- `-` - 範圍（例如：`1-5`）
- `/` - 步進值（例如：`*/5` 每 5 分鐘）
- `?` - 不指定值（僅用於日期或星期）
- `L` - 最後一天（僅用於日期或星期）
- `W` - 工作日（僅用於日期）
- `#` - 第 N 個星期幾（僅用於星期，例如：`MON#2` 第二個週一）

## 技術實作

### 核心演算法

#### 1. Cron 表達式解析

需要實作：

- 解析 5 個欄位
- 處理特殊符號（`*`, `,`, `-`, `/`）
- 驗證值的有效性
- 計算下一次執行時間

#### 2. 人類可讀解釋生成

需要實作：

- 分析各欄位的模式
- 生成自然語言描述
- 處理複雜的組合情況

#### 3. 執行時間計算

需要實作：

- 根據當前時間計算下一次執行時間
- 計算未來 N 次執行時間
- 處理時區問題（可選）

### 函式庫選項

#### 選項 A：自行實作（推薦）

優點：

- 無外部依賴
- 完全控制
- 檔案小

缺點：

- 需要自行實作所有邏輯
- 測試工作較多

#### 選項 B：使用現有函式庫

可能的函式庫：

- `cron-parser` (Node.js，需適配瀏覽器)
- `later.js` (已停止維護)
- 自行實作輕量級版本

**建議**：自行實作，因為：

1. Cron 表達式解析邏輯相對簡單
2. 不需要複雜的排程功能
3. 保持專案無依賴

## 測試案例

### 基本測試

| 輸入          | 預期輸出             |
| ------------- | -------------------- |
| `0 9 * * *`   | "每天 09:00"         |
| `0 9 * * 1-5` | "每週一至週五 09:00" |
| `*/5 * * * *` | "每 5 分鐘"          |
| `0 0 1 * *`   | "每月 1 號 00:00"    |

### 邊界測試

| 輸入         | 預期行為                  |
| ------------ | ------------------------- |
| `60 * * * *` | 顯示錯誤：分鐘應為 0-59   |
| `* * * *`    | 顯示錯誤：應包含 5 個欄位 |
| `0 25 * * *` | 顯示錯誤：小時應為 0-23   |
| `0 0 32 * *` | 顯示錯誤：日期應為 1-31   |

### 複雜測試

| 輸入             | 預期輸出                      |
| ---------------- | ----------------------------- |
| `0 9-17 * * 1-5` | "每週一至週五 09:00 至 17:00" |
| `0 0 1,15 * *`   | "每月 1 號和 15 號 00:00"     |
| `0 */2 * * *`    | "每 2 小時"                   |
| `0 0 * * 0,6`    | "每週六和週日 00:00"          |

## 資料結構

### Cron 表達式物件

```javascript
{
  minute: '*',      // 分鐘欄位
  hour: '9',       // 小時欄位
  day: '*',        // 日期欄位
  month: '*',      // 月份欄位
  weekday: '1-5'   // 星期欄位
}
```

### 解析結果物件

```javascript
{
  expression: '0 9 * * 1-5',
  humanReadable: '每週一至週五 09:00',
  nextExecution: '2025-12-20 09:00:00',
  futureExecutions: [
    '2025-12-20 09:00:00',
    '2025-12-21 09:00:00',
    // ...
  ],
  isValid: true,
  errors: []
}
```

---

## 注意事項

1. **時區處理**：預設使用本地時區，可選支援 UTC
2. **月份和星期的名稱**：支援數字和名稱（JAN-DEC, SUN-SAT）
3. **星期幾的差異**：某些系統使用 0-6（週日=0），某些使用 1-7（週日=7），需明確說明
4. **效能考量**：計算未來執行時間時，避免計算過多（建議最多 10-20 次）
5. **錯誤處理**：提供清晰的錯誤訊息和修正建議
