# 條碼與 QR Code 生成器功能規格

## 功能概述

參考網站：https://www.barcodeocean.com/zh

提供條碼（Barcode）和 QR Code 的生成功能，支援多種條碼格式和自訂選項。

---

## 核心功能

### 1. 生成條碼（Barcode Generator）

#### 1.1 功能描述

- **功能描述**：生成各種格式的條碼圖片
- **輸入**：條碼內容（文字、數字）
- **輸出**：條碼圖片（PNG、SVG 格式）

#### 1.2 支援的條碼類型

| 條碼類型 | 說明 | 支援字元 |
|---------|------|---------|
| CODE-128 | 最常用的條碼格式，支援 ASCII 字元 | 數字、英文字母、符號 |
| CODE-39 | 標準條碼格式 | 數字、大寫字母、部分符號 |
| EAN-13 | 歐洲商品編號（13 位） | 數字（12 位 + 檢查碼） |
| EAN-8 | 歐洲商品編號（8 位） | 數字（7 位 + 檢查碼） |
| UPC-A | 美國商品編號（12 位） | 數字（11 位 + 檢查碼） |
| UPC-E | 美國商品編號（6 位） | 數字（6 位） |
| ITF-14 | 交錯式 2 of 5（14 位） | 數字（13 位 + 檢查碼） |
| Codabar | 庫德巴條碼 | 數字、部分符號 |

#### 1.3 基本設定選項

| 選項 | 說明 | 預設值 | 範圍 |
|------|------|--------|------|
| 條碼類型 | 選擇條碼格式 | CODE-128 | 見上方列表 |
| 條形高度 | 條碼高度（像素） | 100 | 50-500 |
| 條形寬度 | 單個條形寬度（像素） | 2 | 1-10 |
| 上下邊距 | 上下留白（像素） | 15 | 0-100 |
| 左右邊距 | 左右留白（像素） | 15 | 0-100 |
| 字元大小 | 底部文字大小（像素） | 24 | 10-50 |
| 顯示文字 | 是否顯示條碼下方文字 | 是 | 是/否 |

#### 1.4 進階設定選項

| 選項 | 說明 | 預設值 |
|------|------|--------|
| 前景色 | 條碼顏色 | #000000（黑色） |
| 背景色 | 背景顏色 | #FFFFFF（白色） |
| 文字顏色 | 底部文字顏色 | #000000（黑色） |
| 字型 | 文字字型 | Arial |
| 對齊方式 | 文字對齊 | 置中 |

#### 1.5 輸出格式

- **PNG**：點陣圖格式，適合一般使用
- **SVG**：向量圖格式，可無限縮放且保持清晰

---

### 2. 生成 QR Code

#### 2.1 功能描述

- **功能描述**：生成 QR Code 二維碼圖片
- **輸入**：文字、網址、或其他內容
- **輸出**：QR Code 圖片（PNG、SVG 格式）

#### 2.2 基本設定選項

| 選項 | 說明 | 預設值 | 範圍 |
|------|------|--------|------|
| 尺寸大小 | QR Code 尺寸（像素） | 300 | 100-2000 |
| 容錯等級 | 錯誤修正等級 | M（中） | L（低）/M（中）/Q（高）/H（最高） |
| 上下邊距 | 上下留白（像素） | 20 | 0-100 |
| 左右邊距 | 左右留白（像素） | 20 | 0-100 |
| 顯示邊框 | 是否顯示邊框 | 是 | 是/否 |

#### 2.3 進階設定選項

| 選項 | 說明 | 預設值 |
|------|------|--------|
| 前景色 | QR Code 顏色 | #000000（黑色） |
| 背景色 | 背景顏色 | #FFFFFF（白色） |
| Logo 嵌入 | 在 QR Code 中心嵌入 Logo | 否 |
| Logo 圖片 | Logo 圖片檔案 | - |
| Logo 大小 | Logo 尺寸（相對於 QR Code） | 20% |

#### 2.4 容錯等級說明

| 等級 | 說明 | 可損壞比例 |
|------|------|-----------|
| L（低） | 約 7% 的碼字可被恢復 | ~7% |
| M（中） | 約 15% 的碼字可被恢復 | ~15% |
| Q（高） | 約 25% 的碼字可被恢復 | ~25% |
| H（最高） | 約 30% 的碼字可被恢復 | ~30% |

#### 2.5 輸出格式

- **PNG**：點陣圖格式，適合一般使用
- **SVG**：向量圖格式，可無限縮放且保持清晰

## 技術實作

### 函式庫選項

#### 選項 A：使用 jsbarcode（條碼）+ qrcode.js（QR Code）

**優點**：
- 成熟穩定的函式庫
- 支援多種條碼格式
- 輕量級，無外部依賴
- 支援 SVG 輸出

**缺點**：
- 需要載入兩個函式庫
- 部分進階功能可能需要自行實作

**CDN 連結**：
- jsbarcode: `https://cdn.jsdelivr.net/npm/jsbarcode@3.11.5/dist/JsBarcode.all.min.js`
- qrcode.js: `https://cdn.jsdelivr.net/npm/qrcode@1.5.3/build/qrcode.min.js`

#### 選項 B：使用 CDN 載入

**建議**：使用選項 A，因為：
1. 兩個函式庫都很成熟
2. 功能完整
3. 檔案大小適中
4. 支援 SVG 輸出

## 資料結構

### 條碼設定物件

```javascript
{
  type: 'CODE-128',        // 條碼類型
  content: '1234567890',  // 條碼內容
  height: 100,             // 條形高度
  width: 2,                // 條形寬度
  marginTop: 15,           // 上邊距
  marginBottom: 15,        // 下邊距
  marginLeft: 15,          // 左邊距
  marginRight: 15,         // 右邊距
  fontSize: 24,            // 字元大小
  showText: true,          // 顯示文字
  foregroundColor: '#000000',  // 前景色
  backgroundColor: '#FFFFFF',  // 背景色
  textColor: '#000000',        // 文字顏色
  font: 'Arial'                // 字型
}
```

### QR Code 設定物件

```javascript
{
  content: 'https://example.com',  // QR Code 內容
  size: 300,                        // 尺寸
  errorCorrectionLevel: 'M',        // 容錯等級
  margin: 20,                       // 邊距
  showBorder: true,                 // 顯示邊框
  foregroundColor: '#000000',       // 前景色
  backgroundColor: '#FFFFFF',        // 背景色
  logo: null,                       // Logo 圖片（Base64 或 URL）
  logoSize: 0.2                     // Logo 大小（相對於 QR Code）
}
```

## 注意事項

1. **條碼格式限制**：不同條碼類型對輸入內容有不同要求，需要進行驗證
2. **檔案大小**：SVG 格式檔案較小，PNG 格式檔案較大
3. **瀏覽器相容性**：確保使用的函式庫支援主流瀏覽器
4. **效能考量**：即時預覽時使用防抖（debounce）避免頻繁重新生成
5. **Logo 嵌入**：QR Code 的 Logo 不應過大，以免影響掃描
