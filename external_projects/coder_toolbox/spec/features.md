# 功能規格說明

## 工具分類

### 1. 程式碼格式化/壓縮工具

#### 1.1 HTML 格式化 / 壓縮

- **功能描述**：將 HTML 程式碼格式化（美化）或壓縮（最小化）
- **輸入**：HTML 原始碼
- **輸出**：格式化或壓縮後的 HTML
- **選項**：
  - 縮排方式（空格/Tab）
  - 縮排大小（2/4 空格）
  - 壓縮選項

#### 1.2 CSS 格式化 / 壓縮 / 優化

- **功能描述**：CSS 樣式表的格式化、壓縮、自動優化
- **輸入**：CSS 原始碼
- **輸出**：處理後的 CSS
- **選項**：
  - 格式化風格
  - 壓縮等級
  - 自動前綴補全
  - 合併重複規則

#### 1.3 JavaScript 格式化 / 混淆 / 壓縮

- **功能描述**：JS 程式碼的美化、混淆保護、壓縮
- **輸入**：JavaScript 原始碼
- **輸出**：處理後的 JavaScript
- **選項**：
  - 格式化（美化）
  - 混淆（變數重命名、字串加密）
  - 壓縮（移除空白、註解）

---

### 2. 編碼工具

#### 2.1 Base64 編碼/解碼

- **功能描述**：文字與 Base64 的相互轉換
- **特色功能**：支援自定義碼表
- **輸入**：文字或 Base64 字串
- **輸出**：編碼或解碼結果
- **選項**：
  - 標準 Base64
  - URL 安全 Base64
  - 自定義碼表

#### 2.2 Unicode / HTML 實體編碼

- **功能描述**：Unicode 與 HTML 字符實體的轉換
- **輸入**：文字內容
- **輸出**：編碼結果
- **格式**：
  - HTML 實體（`&#x4E2D;` 或 `&#20013;`）
  - Unicode 轉義（`\u4E2D`）

#### 2.3 URL 編碼/解碼

- **功能描述**：URL 編碼（Percent-encoding）處理
- **輸入**：URL 或文字
- **輸出**：編碼或解碼結果
- **方法**：
  - encodeURI / decodeURI
  - encodeURIComponent / decodeURIComponent

---

### 3. 加密工具

#### 3.1 雜湊（Hash）計算

- **功能描述**：計算文字或檔案的雜湊值
- **支援演算法**：
  - MD5
  - SHA-1
  - SHA-256
  - SHA-384
  - SHA-512
- **輸入**：文字或檔案
- **輸出**：雜湊值（十六進位字串）

#### 3.2 對稱加密/解密

- **功能描述**：使用對稱加密演算法加解密
- **支援演算法**：
  - AES (128/192/256)
  - DES
  - Triple DES (3DES)
  - RC4
  - Rabbit
- **選項**：
  - 加密模式（CBC/ECB/CTR 等）
  - 填充方式（PKCS7/ZeroPadding 等）
  - 輸出格式（Base64/Hex）

### 4. 圖片工具

#### 4.1 Data URI / Base64 圖片轉換

- **功能描述**：圖片檔案與 Data URI 的相互轉換
- **支援格式**：PNG, JPEG, GIF, WebP, SVG
- **功能**：
  - 圖片 → Data URI
  - Data URI → 圖片下載

#### 4.2 PNG 轉 ICO（Favicon 製作）

- **功能描述**：將 PNG 圖片轉換為 ICO 格式
- **輸入**：PNG 圖片
- **輸出**：ICO 檔案
- **尺寸選項**：16x16, 32x32, 48x48, 64x64, 128x128, 256x256

#### 4.3 QR Code 二維碼生成

- **功能描述**：生成 QR Code 二維碼圖片
- **輸入**：文字、網址、或其他內容
- **選項**：
  - 尺寸大小
  - 容錯等級（L/M/Q/H）
  - 前景色/背景色
  - Logo 嵌入（可選）
- **輸出格式**：PNG、SVG

#### 4.4 條碼生成器

- **功能描述**：生成各種格式的條碼圖片
- **輸入**：條碼內容（文字、數字）
- **支援格式**：
  - CODE-128（最常用）
  - CODE-39
  - EAN-13 / EAN-8
  - UPC-A / UPC-E
  - ITF-14
  - Codabar
- **選項**：
  - 條形高度/寬度
  - 邊距設定
  - 字元大小
  - 前景色/背景色
  - 字型選擇
- **輸出格式**：PNG、SVG

### 6. 時間工具

#### 6.1 Crontab Guru - Cron 表達式解析器

- **功能描述**：解析和解釋 Cron 排程表達式，提供人類可讀的說明
- **參考網站**：https://crontab.guru/
- **輸入**：Cron 表達式（5 個欄位：分鐘 小時 日期 月份 星期）
- **輸出**：
  - 人類可讀的解釋（例如："每天 09:00"）
  - 下一次執行時間
  - 未來 10 次執行時間預覽
  - 語法驗證與錯誤提示

**Cron 表達式格式**：

```
* * * * *
│ │ │ │ │
│ │ │ │ └─── 星期幾 (0-7, 0 和 7 都代表星期日)
│ │ │ └───── 月份 (1-12)
│ │ └─────── 日期 (1-31)
│ └───────── 小時 (0-23)
└─────────── 分鐘 (0-59)
```

**支援的語法**：

- `*` - 任何值
- `,` - 值列表分隔符（例如：`1,3,5`）
- `-` - 範圍（例如：`1-5`）
- `/` - 步進值（例如：`*/5` 每 5 分鐘）
- 數字 - 具體值
- 星期幾可選用名稱：`SUN`, `MON`, `TUE`, `WED`, `THU`, `FRI`, `SAT`

**功能特色**：

1. **即時解析**：輸入時即時顯示解釋
2. **人類可讀說明**：
   - "每天 09:00"
   - "每週一至週五 09:00"
   - "每月 1 號 00:00"
   - "每 5 分鐘"
3. **執行時間預覽**：
   - 下一次執行時間（完整日期時間）
   - 未來 10 次執行時間列表
4. **隨機生成**：生成隨機的 cron 表達式範例
5. **常用範例**：
   - 每分鐘
   - 每小時
   - 每天
   - 每週
   - 每月
   - 工作日（週一至週五）
6. **語法驗證**：
   - 即時驗證表達式是否有效
   - 顯示錯誤訊息和修正建議
7. **語法說明表格**：顯示各欄位的允許值和特殊符號說明

**UI 元素**：

- Cron 表達式輸入框（5 個欄位或單一輸入框）
- 人類可讀解釋顯示區
- 下一次執行時間顯示
- 未來執行時間列表
- 隨機生成按鈕
- 複製按鈕
- 常用範例按鈕組
- 語法說明表格

**範例輸入/輸出**：

| Cron 表達式   | 人類可讀說明       | 下一次執行          |
| ------------- | ------------------ | ------------------- |
| `0 9 * * *`   | 每天 09:00         | 2025-12-20 09:00:00 |
| `0 9 * * 1-5` | 每週一至週五 09:00 | 2025-12-20 09:00:00 |
| `*/5 * * * *` | 每 5 分鐘          | 2025-12-19 19:25:00 |
| `0 0 1 * *`   | 每月 1 號 00:00    | 2026-01-01 00:00:00 |
| `0 0 * * 0`   | 每週日 00:00       | 2025-12-21 00:00:00 |
