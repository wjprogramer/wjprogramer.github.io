# 實作優先順序

## 階段規劃

### 第一階段：基礎架構 + 核心工具（MVP）

**目標**：建立專案基礎，完成最常用的 3-4 個工具

#### 1.1 專案初始化

- [ ] 建立 Vue 3 + Vite + TypeScript 專案
- [ ] 設定 CSS 變數與基礎樣式
- [ ] 實作 Header + Sidebar + Router 基礎佈局
- [ ] 建立共用元件（CodeEditor、InputOutput、ActionButtons）

#### 1.2 核心工具實作

優先實作最常用的工具：

| 優先度 | 工具名稱            | 難度 | 預估時間 |
| ------ | ------------------- | ---- | -------- |
| P0     | Base64 編碼/解碼    | ⭐   | 2-3 小時 |
| P0     | JSON 格式化/驗證    | ⭐⭐ | 3-4 小時 |
| P0     | URL 編碼/解碼       | ⭐   | 2 小時   |
| P1     | Hash 計算 (MD5/SHA) | ⭐⭐ | 3 小時   |

**第一階段交付物**：

- 可運行的網站骨架
- 4 個核心編碼工具
- 響應式基礎佈局
- 深色模式切換

## 優先度說明

| 優先度 | 說明                     |
| ------ | ------------------------ |
| P0     | 必須完成，MVP 核心功能   |
| P1     | 重要功能，第一版需包含   |
| P2     | 次要功能，可延後實作     |
| P3     | 錦上添花，時間充裕時實作 |

---

## 難度說明

| 難度   | 說明                               |
| ------ | ---------------------------------- |
| ⭐     | 簡單，主要是 UI 實作               |
| ⭐⭐   | 中等，需要整合第三方函式庫         |
| ⭐⭐⭐ | 較難，涉及複雜邏輯或多個函式庫整合 |
