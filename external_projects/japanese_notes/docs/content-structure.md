# 內容架構規劃

## 內容組織方式

### 分類方式

採用**多層分類系統**：

1. **按內容類型**

   - 文法（Grammar）
   - 單字（Vocabulary）
   - 漢字（Kanji）
   - 會話（Conversation）
   - 閱讀（Reading）
   - 文化（Culture）

2. **按難度等級**

   - N5（初級）
   - N4（初級進階）
   - N3（中級）
   - N2（中高級）
   - N1（高級）

3. **按主題標籤**
   - 基礎、進階、日常、商務、旅遊等

### 導航設計

- 主要導航：內容類型
- 次要篩選：難度等級、主題標籤
- 學習路徑：推薦學習順序
- 相關連結：相關文法、單字、漢字

## 內容結構模板

### 基本結構

1. **概述**

   - 內容定義
   - 重要性說明
   - 適用情境

2. **基本說明**

   - 基本概念
   - 使用規則
   - 關鍵要點

3. **例句與說明**

   - 例句（日文 + 中文 + 英文）
   - 例句解析
   - 使用情境

4. **常見用法**

   - 常用表達
   - 變化形式
   - 注意事項

5. **常見錯誤與修正**

   - 錯誤用法
   - 原因分析
   - 正確用法

6. **練習範例**

   - 基礎練習
   - 進階練習
   - 練習要點

7. **相關內容**

   - 相關文法連結
   - 相關單字連結
   - 相關漢字連結

8. **補充資料**（如適用）
   - 文化背景
   - 歷史演變
   - 進階知識

## 內容優先順序

### 第一階段：基礎建立（N5）

1. **基礎文法**

   - 助詞（は、が、を、に、で等）
   - 動詞變化（ます形、て形、た形等）
   - 形容詞（い形容詞、な形容詞）
   - 基本句型

2. **基礎單字**

   - 日常用語
   - 數字、時間、日期
   - 家庭、學校、工作

3. **基礎漢字**
   - 常用漢字（N5 級別）
   - 漢字讀音（音讀、訓讀）

### 第二階段：進階基礎（N4）

1. **進階文法**

   - 複合句型
   - 敬語基礎
   - 被動、使役

2. **進階單字**

   - 生活相關詞彙
   - 情感表達
   - 動作描述

3. **進階漢字**
   - N4 級別漢字
   - 漢字組合

### 第三階段：中級內容（N3）

1. **中級文法**

   - 複雜句型
   - 敬語運用
   - 語態變化

2. **中級單字**

   - 抽象概念
   - 專業術語
   - 慣用語

3. **中級漢字**
   - N3 級別漢字
   - 漢字語彙

### 第四階段：中高級內容（N2）

1. **中高級文法**

   - 高級句型
   - 複雜敬語
   - 文語表現

2. **中高級單字**

   - 商務用語
   - 學術用語
   - 文學用語

3. **中高級漢字**
   - N2 級別漢字
   - 漢字語彙擴充

### 第五階段：高級內容（N1）

1. **高級文法**

   - 複雜文語
   - 古典日語
   - 特殊表現

2. **高級單字**

   - 專業領域詞彙
   - 文學用語
   - 古語

3. **高級漢字**
   - N1 級別漢字
   - 罕見漢字

## 內容關聯性設計

### 相關內容連結

- 每個內容頁面包含「相關內容」區塊
- 例如：助詞「は」 ↔ 助詞「が」、動詞變化

### 內容對比

- 建立對比頁面或區塊
- 例如：は vs が、い形容詞 vs な形容詞

### 難度進階

- 標註內容的難度等級
- 提供學習路徑建議
