# 專案規劃

## 專案目標

建立一個日文學習筆記網站，以 SPA 形式呈現，提供結構化的日文學習內容。

## 技術需求

- SPA (Single Page Application)
- RWD (Responsive Web Design) - 響應式網頁設計
- Light/Dark 模式切換（支援系統設定）
- 多國化 (i18n)：繁體中文、英文
