# 頁面結構規劃

## 主要頁面

### 1. 首頁 (Home)

- 網站介紹
- 快速導航
- 推薦內容
- 學習路徑入口
- 最新內容

### 2. 內容列表頁 (Content List)

- 按內容類型分類瀏覽（文法、單字、漢字等）
- 按難度等級分類瀏覽（N5、N4、N3、N2、N1）
- 標籤篩選
- 搜尋功能
- 收藏內容列表

### 3. 內容詳情頁 (Content Detail)

- 內容標題（日文 + 中文 + 英文）
- 分類標籤（內容類型、難度等級）
- 內容主體（支援多種格式：文字、圖片、表格等）
- 例句與說明
- 相關內容連結
- 內容對比（如適用）
- 練習範例（如適用）
- 收藏按鈕

### 4. 學習路徑頁 (Learning Path)

- 推薦學習順序
- 進度顯示（視覺化）
- 相關內容連結
- 難度等級標註

### 5. 搜尋結果頁 (Search Results)

- 搜尋關鍵字
- 搜尋結果列表
- 篩選選項（類型、難度、標籤）

### 6. 收藏頁 (Favorites)

- 收藏的內容列表
- 分類顯示
- 快速移除收藏

## 導航結構

```text
首頁
├── 學習路徑
├── 內容瀏覽
│   ├── 按內容類型
│   │   ├── 文法
│   │   ├── 單字
│   │   ├── 漢字
│   │   ├── 會話
│   │   ├── 閱讀
│   │   └── 文化
│   └── 按難度等級
│       ├── N5（初級）
│       ├── N4（初級進階）
│       ├── N3（中級）
│       ├── N2（中高級）
│       └── N1（高級）
├── 搜尋
└── 收藏
```

## 頁面元件

### 通用元件

- **Header**（網站標題、語言切換、主題切換、搜尋入口）
- **Navigation**（主要導航選單）
- **Footer**（版權資訊、相關連結）
- **Breadcrumb**（麵包屑導航）

### 內容相關元件

- **ContentCard**（內容卡片）

  - 標題（日文 + 中文/英文）
  - 分類標籤
  - 難度等級
  - 簡短描述
  - 收藏按鈕

- **Tag**（標籤）

  - 內容類型標籤
  - 難度等級標籤
  - 主題標籤

- **RelatedLinks**（相關內容連結）

  - 相關文法連結
  - 相關單字連結
  - 相關漢字連結

- **Comparison**（內容對比）

  - 對比表格
  - 差異說明

- **Example**（例句）

  - 日文例句
  - 假名標註
  - 中文翻譯
  - 英文翻譯
  - 例句解析

- **Practice**（練習範例）
  - 練習題目
  - 答案與解析

## 頁面流程

### 內容瀏覽流程

```
首頁
  ↓
內容列表頁（選擇分類/難度）
  ↓
內容詳情頁（閱讀內容）
  ↓
相關內容連結（繼續學習）
```

### 搜尋流程

```
首頁/任何頁面
  ↓
搜尋框輸入關鍵字
  ↓
搜尋結果頁（顯示結果）
  ↓
內容詳情頁（查看內容）
```

### 學習路徑流程

```
首頁
  ↓
學習路徑頁（查看推薦順序）
  ↓
內容詳情頁（學習內容）
  ↓
標記完成/繼續下一個
```

## 響應式設計考量

### 桌面版（960px+）

- 側邊欄固定顯示
- 雙欄或三欄內容網格
- 完整導航選單

### 平板版（600px - 959px）

- 側邊欄可收合
- 兩欄內容網格
- 簡化導航選單

### 手機版（< 600px）

- 側邊欄改為抽屜式
- 單欄內容網格
- 漢堡選單

## 互動設計

### 內容卡片互動

- 懸停：陰影加深、上浮
- 點擊：跳轉到內容詳情頁
- 收藏：點擊收藏按鈕，即時更新

### 搜尋互動

- 即時搜尋建議
- 搜尋結果高亮關鍵字
- 快速篩選

### 學習路徑互動

- 進度視覺化
- 已完成內容標記
- 快速跳轉到內容

## 無障礙設計

- 所有互動元素具有適當的 `aria-label`
- 鍵盤導航支援
- 焦點狀態明顯
- 色彩對比度符合標準
- 日文內容提供假名標註
