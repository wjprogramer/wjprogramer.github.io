## 房主模式功能

### 1. 建立會議室

**功能描述**：
- 房主點擊「建立會議室」
- 輸入會議主題（必填）
- 輸入會議描述（選填）
- 選擇是否允許匿名參與（預設：允許）
- 選擇會議日期（預設：今天）
- 系統生成唯一的會議 ID（6-8 位數字或字母）
- **自動生成 QR Code**，讓參與者掃描即可加入會議
- 顯示會議 ID（文字顯示 + QR Code 顯示）
- **複製連結功能**：
  - 一鍵複製完整加入連結（包含會議 ID 的完整 URL）
  - 連結格式：`https://wjprogramer.github.io/external_projects/retro/#/join/{meetingId}`
  - 複製成功後顯示提示訊息（如 Toast 通知）
  - 方便透過訊息、Email 等方式分享給參與者
- 提供複製會議 ID 功能（方便手動輸入）
- 開始等待參與者連線

**會議 ID 生成規則**：
- 長度：6-8 位
- 格式：數字 + 字母混合（避免混淆，如 0/O, 1/I）
- 範例：`A3B7C9`, `XY12Z8`

**QR Code 功能詳述**：
- **自動生成**：建立會議室後立即生成 QR Code
- **包含內容**：連線 URL（包含會議 ID）
- **URL 格式**：`https://wjprogramer.github.io/external_projects/retro/#/join/{meetingId}`
- **技術實作**：使用第三方庫生成 QR Code（如 `qrcode.js`）
- **顯示方式**：
  - 大尺寸 QR Code（適合掃描）
  - 會議 ID 文字顯示（可複製）
  - 連線 URL 顯示（可複製）
- **使用場景**：
  - 參與者使用手機相機掃描 QR Code
  - 掃描後自動跳轉到加入頁面
  - 自動填入會議 ID，只需輸入名稱即可加入
- **UI 需求**：
  - QR Code 尺寸：至少 200x200px（Desktop），150x150px（Mobile）
  - 清晰易掃描
  - 支援深色/淺色主題（QR Code 本身為黑白，但背景需適應主題）
  - 可重新生成 QR Code（如需要）

**匿名設定**：
- **允許匿名**：參與者可以選擇每則留言是否匿名
- **不允許匿名**：所有參與者的留言都必須顯示名稱
- 此設定在建立會議室時設定，建立後不可更改

### 2. 參與者管理

**功能描述**：
- 顯示參與者列表
- 每個參與者顯示：
  - 名稱（參與者輸入的）
  - 連線狀態（已連線/已斷線）
  - 參與狀態（已提交/未提交）
  - 提交的項目數量

**參與者操作**：
- **踢除參與者**：
  - 點擊參與者旁的「踢除」按鈕
  - 確認對話框
  - 斷開該參與者的連線
- **黑名單管理**：
  - 將參與者加入黑名單（透過 Peer ID）
  - 黑名單中的 Peer ID 無法再次加入
  - 黑名單儲存於 localStorage

**人數限制**：
- 最多 15 人（包含房主）
- 達到上限時，顯示提示並拒絕新連線

**使用者名稱重複檢查**：
- 參與者加入會議時，系統會檢查輸入的名稱是否與其他參與者（包含房主）重複
- 如果名稱重複，顯示錯誤提示，要求使用者修改名稱
- 檢查時機：點擊「加入」按鈕時
- 錯誤訊息：顯示「此名稱已被使用，請選擇其他名稱」
- 檢查範圍：包含所有已連線的參與者和房主的名稱

### 3. 回顧流程控制

**功能描述**：
- 房主控制整個回顧流程
- 控制按鈕：
  - **開始回顧**：通知所有參與者開始提交回顧內容
  - **結束回顧**：停止接受新的回顧內容
  - **開始討論**：進入討論階段（可選）
  - **結束會議**：結束整個回顧會議

**回顧階段**：
1. **準備階段**：等待參與者加入
2. **收集階段**：參與者提交回顧內容
3. **討論階段**（可選）：參與者可以對內容進行 Emoji 反應與討論
4. **總結階段**：房主查看結果並匯出

### 4. 回顧內容檢視

**功能描述**：
- 顯示所有參與者提交的回顧內容
- 內容分類顯示：
  - **問題點（What went wrong）**
  - **做得好的地方（What went well）**
  - **改進建議（Action items）**
- 顯示每則內容的：
  - 內容文字
  - 作者名稱（如果允許匿名，顯示「匿名」或實際名稱）
  - Emoji 反應（各 emoji 與數量）
  - 提交時間

**排序功能**：
- 按反應熱度排序（預設）
- 按時間排序
- 按作者排序

**篩選功能**：
- 篩選匿名/實名內容
- 篩選特定作者的內容

### 5. 匯出功能

**功能描述**：
- 支援多種匯出格式：
  - **Markdown**：純文字格式，適合文件記錄
  - **圖片（PNG/JPG）**：視覺化格式，適合分享
  - **PDF**（可選）：正式文件格式
- 匯出內容包含：
  - 會議主題與描述
  - 會議日期
  - 參與者列表
  - 所有回顧內容（分類顯示）
  - 反應統計
  - 改進項目清單

**匯出選項**：
- 選擇匯出格式
- 選擇包含的內容（可選：只匯出特定分類）
- 選擇是否包含反應資訊
- 選擇是否包含匿名內容

### 6. 歷史記錄

**功能描述**：
- 自動記錄每次回顧會議
- 記錄內容包含：
  - 會議 ID
  - 會議主題與描述
  - 會議日期
  - 參與者列表
  - 所有回顧內容
  - 反應統計
  - 匯出記錄
- 顯示歷史記錄列表
- 可以查看歷史記錄詳情
- 可以重新匯出歷史記錄
- 可以刪除歷史記錄
- 歷史記錄儲存於 localStorage 或 Google Drive（如果連結）

## 參與者模式功能

### 1. 加入會議室

**功能描述**：
- **方式一：掃描 QR Code**（推薦）
  - 使用手機相機掃描房主顯示的 QR Code
  - 自動跳轉到加入頁面
  - 自動填入會議 ID
  - 只需輸入名稱即可加入
- **方式二：手動輸入**
  - 輸入會議 ID（文字輸入）
  - 輸入名稱（預設：`User-{隨機數字}`）
  - 點擊「加入會議」
- 連線狀態顯示（連線中/已連線/連線失敗）

**使用者名稱記憶功能**：
- 自動記錄上一次使用的名稱
- 下次加入會議時自動帶入上次使用的名稱
- 使用者可以修改名稱
- 名稱儲存於 localStorage

**使用者名稱重複檢查**：
- 加入會議時，系統會檢查輸入的名稱是否與其他參與者（包含房主）重複
- 如果名稱重複，顯示錯誤提示，要求使用者修改名稱
- 檢查時機：點擊「加入」按鈕時
- 錯誤訊息：顯示「此名稱已被使用，請選擇其他名稱」
- 檢查範圍：包含所有已連線的參與者和房主的名稱

**QR Code 掃描功能**：
- 支援使用手機相機掃描 QR Code
- 掃描後自動解析 URL 中的會議 ID
- 自動導航到加入頁面（`#/join/{meetingId}`）
- 自動填入會議 ID，使用者只需輸入名稱
- 如果瀏覽器不支援相機權限，提供手動輸入選項

**連線流程**：
1. **掃描 QR Code 或手動輸入會議 ID**
2. 輸入名稱（自動帶入上次使用的名稱，可修改）
3. 點擊「加入會議」
4. 顯示「連線中...」
5. 透過 WebRTC 連線到房主
6. 連線成功：顯示「已連線」
   - 如果房主已經開始回顧，參與者會自動進入提交階段
   - 如果房主尚未開始回顧，參與者會顯示等待畫面
7. 連線失敗：顯示錯誤訊息，可重試

### 2. 提交回顧內容

**功能描述**：
- 參與者可以提交三種類型的回顧內容：
  - **問題點（What went wrong）**：指出問題或困難
  - **做得好的地方（What went well）**：表揚做得好的地方
  - **改進建議（Action items）**：提出具體的改進建議
- 每種類型可以提交多則內容
- 每則內容可以選擇是否匿名（在房主允許匿名的情況下）
- 提交後可以編輯或刪除自己的內容

**匿名選擇**：
- 如果房主允許匿名：
  - 每則留言旁邊有「匿名」選項
  - 參與者可以選擇該則留言是否匿名
  - 不同留言可以有不同的匿名設定
  - 例如：問題點選擇匿名，感謝的話選擇實名
- 如果房主不允許匿名：
  - 不顯示匿名選項
  - 所有留言都必須顯示名稱

**內容編輯**：
- 提交後可以編輯自己的內容
- 可以刪除自己的內容
- 編輯或刪除後會同步到所有參與者

### 3. Emoji 反應功能

**功能描述**：
- 參與者可以對他人的回顧內容添加 Emoji 反應（如 👍、❤️、😂、😮、😢、🔥 等）
- 每則內容顯示各 emoji 的數量與當前使用者已選的 emoji（高亮）
- 參與者可以：
  - 點擊 emoji 添加反應
  - 再次點擊相同 emoji 移除反應
  - 同時選擇多個不同的 emoji
- 反應變更會即時同步到所有參與者

**反應顯示**：
- 卡片上顯示所有 emoji 反應與數量
- 當前使用者已選擇的 emoji 以高亮顯示
- 可透過「＋」按鈕展開 Emoji 選擇器／工具列，含「更多 emoji」開啟完整選擇器

### 4. Item 留言功能

**功能描述**：
- 每個 item 可以有多筆留言
- 留言顯示：作者、時間、內容
- 支援編輯和刪除自己的留言
- 留言變更會即時同步到所有參與者（P2P 模式）

**留言 UI**：
- Item 卡片右上角顯示留言 icon（僅在有留言時顯示）
  - 顯示留言數量 badge
  - 點擊留言 icon 打開留言 modal dialog
- 反應工具欄（reaction toolbar）中也有留言按鈕
  - 點擊留言按鈕同樣打開留言 modal dialog
- 留言 modal dialog：
  - 顯示 item 內容
  - 顯示所有留言列表（作者、時間、內容）
  - 留言輸入框（支援多行文字）
  - 編輯/刪除按鈕（icon 形式，僅自己的留言顯示）
  - 刪除留言時顯示確認 dialog
- 留言時間顯示：
  - 短時間內（1 小時內）顯示相對時間（如「2 分鐘前」）
  - 超過時間閾值後顯示絕對時間（如「2024-01-15 14:30」）
  - 無論是否在 P2P 模式下，都會持續更新相對時間文字（只更新文字內容，不重新 render 整個留言列表）
  - 相對時間的文字需有 tooltip，顯示完整的絕對時間

**留言權限**：
- 只有留言作者可以編輯或刪除自己的留言
- 所有參與者都可以新增留言

**留言同步**：
- P2P 模式下即時同步留言
- 留言變更通知所有參與者
- 支援留言的即時更新

### 5. 查看結果

**功能描述**：
- 參與者可以查看所有回顧內容
- 內容分類顯示：
  - 問題點
  - 做得好的地方
  - 改進建議
- 顯示反應統計
- 顯示改進項目清單

**排序功能**：
- 按反應熱度排序（預設）
- 按時間排序
- 按作者排序

### 6. 連線管理

**功能描述**：
- 顯示連線狀態（已連線/已斷線/連線中）
- 自動重連機制（可選）
- 斷線提示與重連按鈕

**連線狀態**：
- **已連線**：綠色指示燈
- **已斷線**：紅色指示燈，顯示重連按鈕
- **連線中**：黃色指示燈

## 共用功能

### 1. 主題系統

**功能描述**：
- 支援 Dark Mode 和 Light Mode
- 預設跟隨瀏覽器系統主題（`prefers-color-scheme`）
- 可手動切換主題
- 主題設定儲存於 localStorage

**實作方式**：
- 使用 CSS 變數定義顏色
- 透過 JavaScript 切換 `<html>` 的 `data-theme` 屬性
- 監聽 `prefers-color-scheme` 媒體查詢

**UI 需求**：
- 主題切換按鈕：位於設定選單或 Header
- 切換動畫：平滑的顏色過渡

### 2. 多國語系

**功能描述**：
- 支援多種語言
- 預設語言跟隨瀏覽器設定
- 可手動切換語言
- 語言設定儲存於 localStorage

**支援語言**：
- 繁體中文（zh-TW）
- English（en）
- 日本語（ja）

**實作方式**：
- 使用 JavaScript 物件儲存翻譯文字
- 透過 JavaScript 動態替換文字內容
- 語言檔案：`js/data/i18n.js`

**UI 需求**：
- 語言切換：使用 Dropdown 下拉選單
- 位置：位於 Header 的語言切換按鈕，點擊後顯示下拉選單
- 下拉選單選項：
  - 繁體中文（zh-TW）
  - English（en）
  - 日本語（ja）
- 當前選中的語言在選單中標示（如勾選或高亮）
- 點擊選項後立即切換語言並關閉選單

### 3. 響應式設計（RWD）

**功能描述**：
- 支援 Desktop、Tablet、Mobile
- 觸控優化
- 自適應佈局

**斷點定義**：
- Mobile：< 768px
- Tablet：768px - 1023px
- Desktop：≥ 1024px

**設計原則**：
- Mobile First
- 觸控目標大小：至少 44x44px
- 字體大小：Mobile 至少 16px（避免自動縮放）

### 4. 資料儲存

**功能描述**：
- 使用 localStorage 或 Google Drive 儲存資料
- 使用命名空間避免衝突
- 資料結構設計見 `spec/data-structure.md`

**儲存項目**：
- 使用者設定（主題、語言）
- 使用者名稱
- 回顧會議記錄
- 歷史記錄

**Google Drive 整合（可選）**：
- 使用者可以選擇連結 Google Drive
- 連結後，資料會同步到 Google Drive
- 未連結時，使用 localStorage
- 需要使用者授權 Google Drive API

### 5. 使用者認證（可選）

**功能描述**：
- 使用者可選擇是否登入
- 登入後可連結 Google Drive
- 未登入時使用 localStorage
- 登入方式：
  - Google 帳號登入（使用 Google OAuth）
  - 其他方式（可選）

**登入狀態**：
- 顯示登入狀態
- 可以登出
- 登出後清除登入資訊（但保留本地資料）

### 6. 設定頁面

**功能描述**：
- 提供統一的設定頁面，管理所有應用程式設定
- 設定項目包括：
  - 主題切換（Dark/Light/System）
  - 語言選擇
  - Google Drive 連結狀態
  - 資料管理

**資料管理功能**：
- **清除全部資料**：
  - 提供「清除全部資料」按鈕
  - 清除所有 localStorage 中與應用程式相關的資料
  - 包括：設定、歷史記錄、使用者名稱等
  - 需要確認對話框（避免誤操作）
  - 清除後會重置為預設設定
  - **注意**：此操作不可復原，請謹慎使用
- **清除歷史記錄**：
  - 僅清除歷史記錄，保留其他設定
  - 需要確認對話框

**UI 需求**：
- 設定頁面：卡片式設計，分類清楚
- 清除資料按鈕：使用危險色（紅色）標示
- 確認對話框：清楚說明將清除的資料類型
- 清除成功後顯示 Toast 通知

## 使用者體驗需求

### 1. 載入效能

- 首次載入時間：< 3 秒
- 頁面切換：流暢無卡頓
- 動畫：60 FPS

### 2. 錯誤處理

- 連線失敗：清楚的錯誤訊息與重試按鈕
- 資料載入失敗：提示訊息
- 瀏覽器不支援：提示升級瀏覽器
- Google Drive API 錯誤：清楚的錯誤訊息與處理建議

### 3. 無障礙設計

- 鍵盤導航支援
- ARIA 標籤
- 顏色對比度符合 WCAG AA 標準

### 4. 離線支援（可選）

- PWA 支援
- Service Worker
- 離線時顯示提示

## 功能優先順序

### P0（第一階段 - MVP 必須實作）

1. **基礎架構**：SPA、路由、主題系統、多國語系
2. **單人回顧模式**：建立回顧、新增項目、匯出 Markdown
3. **主題系統**：Dark/Light Mode
4. **多國語系**：繁體中文、English
5. **RWD**：基本響應式設計
6. **資料儲存**：localStorage

### P1（第二階段 - P2P 協作）

1. **P2P 連線**：使用 PeerJS，只支援免費信號伺服器
2. **房主模式**：建立會議室、管理參與者、控制流程
