# UI/UX 設計規格

## 設計原則

1. **輕鬆友善**：營造輕鬆、溫暖的氛圍，降低檢討時的緊張感
2. **簡潔明瞭**：介面簡潔，功能清晰
3. **易於使用**：減少操作步驟，提高效率
4. **視覺層次**：重要資訊突出顯示
5. **一致性**：保持設計風格一致
6. **無障礙**：符合基本無障礙標準

**設計特點**（基於實際瀏覽觀察）：
- **溫暖親切的配色**：
  - 主背景：淺藍色/青綠色（`#E8F4F8` 或類似），給人清新、輕鬆的感覺
  - 側邊欄：純白色背景，與主內容區形成對比
  - 強調色：溫暖的橘色（`#FFB347` 或類似），用於重要元素和按鈕
  - 文字：柔和的深灰色（非純黑），更舒適閱讀
- **輕鬆友善的氛圍**：營造輕鬆、溫暖的氛圍，降低檢討時的緊張感
- **三欄式佈局**（Desktop）：
  - 左側：白色導航欄，固定寬度
  - 中間：淺藍色內容區，主要內容展示
  - 右側：可選的額外資訊區（如角色列表、相關連結等）
- **卡片式佈局**：使用卡片容器組織內容，清晰分層
- **圓潤設計**：使用較大的圓角（16-20px），柔和的視覺效果
- **柔和陰影**：使用非常柔和的陰影，增加層次感但不突兀
- **豐富的動畫**：由於 retro 不是時常使用的 app，可以有更多動畫和 transition 效果（在合理範圍內）
  - 頁面切換：平滑的淡入淡出效果
  - 元素出現：從下往上滑入 + 淡入
  - 懸停效果：輕微的提升和放大
- **自然元素**：可選使用輕量的自然元素（如小植物、雲朵等插圖）增加親切感
- **清晰的視覺層次**：使用字體大小、顏色、間距建立視覺層次
- **舒適的文字排版**：
  - 大標題：使用較大字體（32-40px），突出重要資訊
  - 正文：舒適的行距（1.6-1.8），易於閱讀
  - 日文和英文混排：支援多語言的良好排版

**適用場景**：
- 適合各種類型的團隊
- 營造輕鬆、友善的檢討氛圍
- 降低檢討時的緊張感
- 提升使用者參與度和互動體驗

## 共同設計元素

### 1. 回顧卡片設計

**基本結構**：
- 卡片容器：溫暖的米白色背景（Light Mode）或深色背景（Dark Mode）
- 圓角：16-20px（較大的圓角，更柔和親切）
- 陰影：非常柔和的 box-shadow（`rgba(0, 0, 0, 0.06)` 或更淡）
- 內距：20px-28px（較大的內距，更舒適）
- 邊框：可選的柔和邊框（`rgba(0, 0, 0, 0.08)`）

**內容區域**：
- **標題區域**：顯示回顧類型（問題點/做得好的地方/改進建議）
- **內容區域**：顯示回顧文字
- **操作區域**：Emoji 反應按鈕（＋展開工具列／選擇器）、編輯/刪除按鈕（如果是自己的內容）
- **資訊區域**：作者名稱、時間、反應（各 emoji 與數量）

**狀態**：
- **預設**：正常顯示，帶有輕微的浮動動畫（可選）
- **懸停**：輕微提升效果（`translateY(-4px)`），陰影加深，圓角稍微放大（`scale(1.02)`）
- **已加入反應**：已選擇的 emoji 以高亮顯示（主色邊框/背景），帶有輕微的脈動動畫
- **匿名**：作者名稱顯示為「匿名」或圖示，使用柔和的灰色
- **出現動畫**：卡片出現時有流暢的淡入 + 從下往上滑入動畫（0.5-0.6 秒）

**尺寸**：
- Desktop：最大寬度 600px
- Tablet：最大寬度 500px
- Mobile：全寬（扣除邊距）

### 2. 按鈕設計

**類型**：
- **主要按鈕**：
  - 溫暖的主色背景（如柔和的藍綠色或橘色），白色文字
  - 圓角 12px（較大的圓角，更柔和）
  - 內距：14px 28px（較大的內距）
  - 高度：48px（Mobile 觸控優化，稍大一些）
  - 帶有輕微的漸層效果（可選）
- **次要按鈕**：
  - 透明背景，主色邊框和文字
  - 圓角 12px
  - 內距：14px 28px
  - 懸停時背景色淡入動畫
- **危險按鈕**：
  - 柔和的紅色背景（非鮮紅色），白色文字
  - 用於刪除、踢除等操作
  - 使用較柔和的紅色（如 `#FF8A8A` 而非 `#DC3545`）
- **文字按鈕**：
  - 無背景，主色文字
  - 懸停時有輕微背景色淡入動畫

**狀態**：
- **預設**：正常狀態，帶有輕微的呼吸動畫（可選，非常微妙）
- **懸停**：輕微提升效果（`translateY(-3px)`），陰影加深，輕微放大（`scale(1.05)`）
- **點擊**：按下效果（`translateY(2px)`），帶有彈性動畫（`cubic-bezier(0.68, -0.55, 0.265, 1.55)`）
- **禁用**：降低透明度和飽和度，不可點擊
- **載入狀態**：帶有輕微的脈動動畫

### 3. 模態框設計

**結構**：
- 半透明背景遮罩（`rgba(0, 0, 0, 0.5)`）
- 中央卡片式內容區
- 關閉按鈕（右上角）

**視覺效果**：
- 內容區帶有陰影
- 圓角 16px
- 背景色適應主題

**尺寸**：
- Desktop：最大寬度 600px
- Mobile：全螢幕或接近全螢幕

**動畫**：
- 出現：淡入 + 從下往上滑入 + 輕微縮放 + 彈性效果
- 消失：淡出 + 往下滑出 + 輕微縮小
- 時長：0.5-0.6 秒（較長的動畫時間，更流暢）
- 動畫曲線：`cubic-bezier(0.34, 1.56, 0.64, 1)`（彈性曲線，更生動）

### 4. 參與者列表設計

**項目結構**：
- 頭像/圖示（左側，圓形）
- 名稱（中間）
- 狀態指示（右側）
- 操作按鈕（如踢除）

**狀態指示**：
- 已連線：綠色圓點
- 已斷線：灰色圓點
- 已提交：藍色圓點
- 未提交：白色圓點

### 5. Emoji 反應設計

**基本樣式**：
- 卡片上以「＋」按鈕展開反應工具列，內含預設 emoji（如 👍、❤️、😂、😮、😢）與「更多 emoji」按鈕
- 反應顯示區：各 emoji 以 badge 形式顯示，旁標數量
- 完整選擇器（Emoji Picker）：搜尋、分類，點選後加入反應

**狀態**：
- **未加入該 emoji**：灰色邊框，透明背景
- **已加入該 emoji**：主色邊框/淺主色背景，高亮顯示
- **懸停**：輕微放大效果

### 6. 輸入框設計

**基本樣式**：
- 圓角 12px（較大的圓角）
- 邊框：1px solid，使用柔和的邊框顏色
- 內距：14px 20px（較大的內距）
- 高度：48px（Mobile 觸控優化，稍大一些）
- 背景：溫暖的米白色或淺色背景

**狀態**：
- **預設**：正常邊框顏色
- **聚焦**：邊框顏色加深，顯示外框
- **錯誤**：紅色邊框
- **禁用**：灰色背景，不可編輯

## 響應式設計

### 斷點定義

- **Mobile**：< 768px
- **Tablet**：768px - 1023px
- **Desktop**：≥ 1024px

### 佈局設計

#### Mobile（< 768px）

- **單欄佈局**：所有內容垂直排列
- **回顧卡片**：全寬（扣除邊距）
- **按鈕**：全寬或接近全寬
- **導航**：底部導航欄或漢堡選單
- **字體大小**：至少 16px（避免自動縮放）

#### Tablet（768px - 1023px）

- **雙欄佈局**：部分內容可並排顯示
- **回顧卡片**：最大寬度 500px
- **按鈕**：適中寬度
- **導航**：頂部導航欄

#### Desktop（≥ 1024px）

- **三欄式佈局**（參考搖曳露營）：
  - **左側欄**：白色固定寬度側邊欄（約 200-250px），包含導航選單
  - **中間欄**：淺藍色內容區（主要內容），最大寬度約 800-1000px
  - **右側欄**（可選）：白色側邊欄（約 200-250px），顯示參與者列表、統計等
- **回顧卡片**：最大寬度 600px，居中顯示
- **導航**：左側固定導航欄（參考搖曳露營的導航設計）

## 動畫設計（豐富的動畫效果）

**設計理念**：由於 retro 不是時常使用的 app，可以有更多動畫和 transition 效果，讓使用者體驗更加生動有趣。所有動畫都應該流暢、柔和，符合輕鬆友善的氛圍。

### 1. 卡片出現動畫

**效果**：從下往上滑入 + 淡入 + 輕微縮放 + 彈性效果

**時長**：0.5-0.6 秒

**動畫曲線**：`cubic-bezier(0.34, 1.56, 0.64, 1)`（彈性曲線）

**實作**：
```css
@keyframes slideUpBounce {
  from {
    opacity: 0;
    transform: translateY(30px) scale(0.95);
  }
  60% {
    transform: translateY(-5px) scale(1.02);
  }
  to {
    opacity: 1;
    transform: translateY(0) scale(1);
  }
}

.retro-card {
  animation: slideUpBounce 0.6s cubic-bezier(0.34, 1.56, 0.64, 1);
}
```

**延遲效果**：多個卡片可以有不同的延遲時間，創造波浪式出現效果

### 2. 按鈕點擊動畫

**效果**：彈性縮放 + 按下效果

**時長**：0.3 秒

**動畫曲線**：`cubic-bezier(0.68, -0.55, 0.265, 1.55)`（彈性曲線）

**實作**：
```css
.button:active {
  animation: buttonPress 0.3s cubic-bezier(0.68, -0.55, 0.265, 1.55);
}

@keyframes buttonPress {
  0% { transform: scale(1) translateY(0); }
  50% { transform: scale(0.92) translateY(2px); }
  100% { transform: scale(1) translateY(0); }
}
```

### 3. 頁面切換動畫

**效果**：淡入淡出 + 輕微的滑動效果（參考搖曳露營的頁面切換）

**時長**：0.5-0.6 秒（較長的動畫時間，更流暢）

**動畫曲線**：`ease-in-out` 或 `cubic-bezier(0.4, 0, 0.2, 1)`

**實作**：
```css
.page-transition {
  animation: pageFadeIn 0.6s cubic-bezier(0.4, 0, 0.2, 1);
}

@keyframes pageFadeIn {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
```

**側邊欄動畫**（可選）：
- 側邊欄可以有不同的動畫效果
- 例如：從左側滑入（Desktop）或淡入（Mobile）

### 4. 反應動畫

**效果**：彈性放大 + 顏色變化 + 粒子效果（可選）

**時長**：0.4 秒

**動畫曲線**：`cubic-bezier(0.68, -0.55, 0.265, 1.55)`

**實作**：
```css
.reaction-badge.reaction-badge-active {
  animation: reactionAnimation 0.4s cubic-bezier(0.68, -0.55, 0.265, 1.55);
}

@keyframes reactionAnimation {
  0% { transform: scale(1); }
  30% { transform: scale(1.3); }
  60% { transform: scale(0.95); }
  100% { transform: scale(1); }
}
```

**額外效果**：可以加入輕微的粒子動畫（如小星星或愛心飛出）

### 5. 載入動畫

**效果**：柔和的脈動動畫或骨架屏

**時長**：持續直到載入完成

**實作**：
```css
@keyframes pulse {
  0%, 100% {
    opacity: 1;
  }
  50% {
    opacity: 0.5;
  }
}

.loading {
  animation: pulse 1.5s ease-in-out infinite;
}
```

### 6. 卡片懸停動畫

**效果**：輕微提升 + 陰影加深 + 輕微放大

**時長**：0.3 秒

**實作**：
```css
.retro-card:hover {
  transform: translateY(-6px) scale(1.02);
  box-shadow: 0 8px 24px rgba(0, 0, 0, 0.12);
  transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}
```

### 7. 輸入框聚焦動畫

**效果**：邊框顏色淡入 + 輕微放大

**時長**：0.3 秒

**實作**：
```css
.input:focus {
  transform: scale(1.02);
  border-color: var(--accent-primary);
  box-shadow: 0 0 0 3px rgba(78, 205, 196, 0.1);
  transition: all 0.3s ease;
}
```

### 8. 背景動畫（可選）

**效果**：輕微的浮動動畫或粒子效果

**時長**：持續動畫

**實作**：
```css
@keyframes float {
  0%, 100% {
    transform: translateY(0px);
  }
  50% {
    transform: translateY(-10px);
  }
}

.background-element {
```

## 無障礙設計

### 1. 鍵盤導航

- 所有互動元素可透過 Tab 鍵導航
- 使用 Enter 或 Space 鍵觸發操作
- 清晰的焦點指示器

### 2. ARIA 標籤

- 為互動元素添加 `aria-label`
- 為狀態元素添加 `aria-live`
- 為模態框添加 `role="dialog"`

### 3. 顏色對比度

- 文字與背景對比度至少 4.5:1（WCAG AA）
- 大文字（18pt+）對比度至少 3:1

### 4. 觸控目標

- 所有可點擊元素至少 44x44px
- 元素間距足夠，避免誤觸

## 字體選擇

### 推薦字體

1. **中文**：
   - Noto Sans TC（繁體中文）
   - Noto Sans SC（簡體中文）

2. **英文**：
   - Inter
   - Roboto
   - System Font Stack

3. **等寬字體**（如需要）：
   - JetBrains Mono
   - Fira Code

### 字體大小（參考搖曳露營的排版）

- **大標題**：40-48px（Desktop）/ 32px（Mobile）- 用於頁面主標題
- **標題 1**：32px（Desktop）/ 24px（Mobile）- 用於區塊標題
- **標題 2**：24px（Desktop）/ 20px（Mobile）- 用於子標題
- **標題 3**：20px（Desktop）/ 18px（Mobile）- 用於小標題
- **正文**：16px（行距 1.6-1.8，舒適的閱讀體驗）
- **小字**：14px（行距 1.5）
- **極小字**：12px（行距 1.4）

### 文字排版（參考搖曳露營）

- **行距**：正文使用 1.6-1.8 的行距，提供舒適的閱讀體驗
- **字間距**：日文和中文使用適當的字間距（`letter-spacing: 0.02em`）
- **段落間距**：段落之間使用較大的間距（24-32px），避免擁擠
- **對齊方式**：左對齊（日文和中文），左對齊或兩端對齊（英文）
